# UI kit · Micrositio móvil

Recreación navegable del micrositio a 390 px. No hay producto previo: estas pantallas son la propuesta de referencia construida con los componentes del sistema.

- `index.html`: historia completa con scroll real: Hero → Escala → Dibújalo tú → Cohorte → Mapa → Esperanza → Formulario → Carrusel.
- `pantallas.html`: las 8 pantallas clave lado a lado (390×844), incluido Dibújalo antes/después.

Archivos: `kit-utils.jsx` (hook de paso activo, estilos y datos de ejemplo), `Hero.jsx`, `EscenaEscala.jsx`, `DibujaloTu.jsx`, `EscenaCohorte.jsx`, `EscenaMapa.jsx`, `FormularioWrapped.jsx` (incluye `Esperanza`), `CarruselTarjetas.jsx`.

Datos: 61% (18 años), 47% (25 años), 66.7/52.1/50.3 (cohorte 2012), 37.1 M y 15 mil secciones vienen del brief. Valores intermedios por edad, valores por estado y municipales son **ilustrativos**.
